# متجر الخدمات والمنتجات الرقمية (X-Z Store) — Production-Ready Digital Store Platform

منصة تجارة إلكترونية سحابية متكاملة لبيع وشحن المنتجات والخدمات الرقمية (شدات ببجي، جواهر فري فاير، اشتراكات تيليجرام بريميوم، بطاقات الهدايا، خدمات السوشيال ميديا، وحسابات الذكاء الاصطناعي)، مصممة وفق أحدث المعايير البرمجية والأمنية مع دعم أصيل للغة العربية (RTL) وتصميم دارك مود فاخر مستوحى من المتجر المرجعي `x-z.store`.

---

## 🚀 المميزات الرئيسية للمنصة

### 1. واجهة المتجر للعملاء (Storefront)
- **تصميم RTL عربي فخم ومتجاوب**: متوافق تماماً مع الهواتف الذكية والأجهزة اللوحية وأجهزة الكمبيوتر، مع تأثيرات Glassmorphism وألوان داكنة عميقة.
- **عرض الأقسام والخدمات الحية**: تصنيفات ديناميكية مسترجعة من قاعدة البيانات (ألعاب، اشتراكات، بطاقات، سوشيال ميديا، ذكاء اصطناعي).
- **نموذج طلب ديناميكي متطور**: تتغير حقوله تلقائياً بحسب نوع الخدمة (مثل: Player ID للألعاب، رابط الحساب لخدمات التواصل، البريد الإلكتروني للحسابات).
- **احتساب فوري للأسعار والخصومات**: يتم التحقق من الأسعار وقسائم الخصم (Coupons) على الخادم حصراً لمنع التلاعب.
- **محفظة رقمية ذكية**: شحن يدوي محلي عبر سيريتل كاش (Syriatel Cash)، إم تي إن كاش (MTN Cash)، شام كاش (Sham Cash)، حوالات الهرم، والعملات المشفرة (USDT).

### 2. محرك المعاملات المالية الآمن (Financial Ledger Engine)
- **حماية تامة من الإنفاق المزدوج**: استخدام المعاملات الذرية (`prisma.$transaction`) مع قفل السجلات لمنع تكرار الخصم أو تضارب الأرصدة.
- **دفتر أستاذ محاسبي (Audit Ledger)**: تسجيل غير قابل للتعديل لكل حركة مالية (إيداع، خصم طلب، استرداد، تعديل إداري) مع حفظ الرصيد قبل وبعد كل حركة.
- **منع تكرار اعتماد الشحن (Idempotency)**: حماية مشددة تمنع اعتماد طلب الشحن الواحد أكثر من مرة.
- **استرداد تلقائي ذري**: في حال إلغاء الطلب أو إنجازه جزئياً، تتم إعادة القيمة المستحقة فورياً إلى محفظة العميل مع تسجيل القيد المالي المقابل.

### 3. لوحة التحكم الإدارية الفعّالة (`/admin`)
- **لوحة مؤشرات تشغيلية حية**: إجمالي المبيعات، عدد الطلبات، طلبات الشحن المعلقة، عدد العملاء، وإحصائيات الحالات.
- **إدارة طلبات شحن المحفظة**: فحص الحوالات، معاينة إشعار التحويل المرفق، والموافقة أو الرفض مع تدوين السبب.
- **إدارة ومتابعة مراحل الطلبات**: الانتقال بين الحالات (`PENDING` -> `PROCESSING` -> `COMPLETED`) وإدخال بيانات وأكواد التفعيل المسلمة للعميل.
- **إدارة الكتالوج والأسعار**: إدارة التصنيفات، المنتجات، الباقات، وحقول الإدخال المخصصة.
- **إدارة العملاء والكوبونات والإعدادات**: متابعة الأرصدة، إنشاء أكواد الخصم، وتعديل بيانات حسابات الدفع المعلنة.

## 🛠 البنية التقنية (Tech Stack)

- **Frontend**: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Lucide Icons.
- **Backend**: Next.js Server Components, Server Actions & Route Handlers, Zod Validation.
- **Database & ORM**: Prisma ORM مع SQLite (جاهز للتحويل إلى PostgreSQL عبر تغيير Provider).
- **Security & Auth**: تجزئة كلمات المرور عبر `bcryptjs`، جلسات مشفرة عبر Secure HTTP-Only Cookies، ونظام RBAC صارم.
- **Service Integration**: طبقة تجريد `ServiceProviderAdapter` تدعم التنفيذ اليدوي ومزودات API الخارجية.

## 💻 طريقة التشغيل محلياً (Local Setup Instructions)

### المتطلبات الأساسية
- Node.js (v18 فما فوق).
- npm أو pnpm أو yarn.

### خطوات التشغيل
1. **تثبيت التبعيات**:
   ```bash
   npm install
   ```

2. **تهيئة البيئة وقاعدة البيانات**:
   ```bash
   # توليد Prisma Client ومزامنة قاعدة البيانات
   npx prisma generate
   npx prisma db push

   # بذر البيانات الأولية وحسابات المدير والعملاء والمنتجات
   node prisma/seed.js
   ```

3. **تشغيل اختبارات التحقق الشاملة**:
   ```bash
   node scripts/verify-system.js
   ```

4. **بدء خادم التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## 🔒 قائمة التحقق قبل النشر للإنتاج (Production Checklist)

1. استبدال مفتاح `JWT_SECRET` في `.env` بسلسلة عشوائية آمنة 64-bit.
2. تفعيل خيار `Secure` لملفات تعريف الارتباط (Cookies) عند ربط شهادة SSL/HTTPS.
3. ربط التخزين السحابي (AWS S3 أو Cloudflare R2) في حال الرغبة بحفظ إثباتات الدفع خارج الخادم المحلي.
4. إدخال أرقام حسابات وسائل الدفع الحقيقية (سيريتل كاش، شام كاش، MTN) من صفحة الإعدادات في لوحة الإدارة `/admin/settings`.
